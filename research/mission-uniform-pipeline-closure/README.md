# Preserved, superseded worker proposals

These are inert historical archives, not active verification code or tests.
The accepted pipeline is the implementation already integrated on main.

`manifest.json` records nine unique worker commits as full-index Git patches,
plus six previously uncommitted Linux draft files as byte-for-byte snapshots.
The original commits' trees were reconstructed with an isolated Git index and
compared with their original tree IDs before retirement. Snapshots were read
back and compared with their original bytes. No archived program was executed.

All archive paths disable Git text conversion to preserve their exact bytes.
Nothing here is registered with CMake, the scenario catalogue or unittest
discovery. Do not reapply the old RED checkpoints or dispatch prototypes over
the reviewed pipeline without a new, explicit development contract.

Original branches and raw preservation evidence were backed up outside the
retiring worktrees under `out/verification-synthetic/mission-close-inventory-*`.
The small Git bundle in `history/` is also versioned here alongside the patches
and snapshots; its hash and source references are recorded in the manifest. Native closure
receipts and final publication checks are documented in the mission reports.
